# Patrick Del Ayre — Developer Portfolio

Personal portfolio website of **Patrick Froilan S. Del Ayre**, a full-stack web and native Android mobile application developer based in Bulacan, Philippines.

## 🚀 Featured Projects

- **[YTO Express Logistics Platform](https://github.com/Natoy0123/YTO-Express-App):** Multi-role logistics and parcel delivery management system built with Native Android (Java), MapLibre, CameraX, React 19, and Node.js/Express MongoDB backend.
- **[Hagonoy GroundWatch](https://github.com/Natoy0123/hagonoy-groundwatch):** Civic telemetry and environmental GIS platform addressing coastal land subsidence and sunny-day tidal flooding in Bulacan. Live at [hagonoy-groundwatch-tik7.onrender.com](https://hagonoy-groundwatch-tik7.onrender.com).
- **[MorphLens](https://github.com/Natoy0123/morphlens):** Browser-based AI portrait and identity synthesis studio built with React 19, Vite, Tailwind CSS v4, and Pollinations AI. Live at [personacraft-app.onrender.com](https://personacraft-app.onrender.com).

## 🛠️ Tech Stack

- **Markup & Styling:** Semantic HTML5, Modern CSS (Fluid Typography, Custom Properties, Responsive Grid & Flexbox)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Testing:** Playwright E2E cross-browser testing

## 📦 Deployment on Render

This site is pre-configured for instant zero-configuration deployment on Render:

1. Open [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** &rarr; **Static Site**.
3. Connect repository: `Natoy0123/portfolio`.
4. Render will automatically read `render.yaml`:
   - **Build Command:** *(leave empty)*
   - **Publish Directory:** `./`
5. Click **Deploy**.
